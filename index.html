Ace Code Claimer

A convenient userscript that automatically claims bonus codes on Stake.com. This guide offers a Quick Setup (for users familiar with Tampermonkey) and a Detailed Setup below. Even if you’re new to this, following the steps carefully will only take a few minutes.

Quick Setup (Fast Instructions)

  1. Install Tampermonkey in your browser. (Detailed guide)
  2. Enable Developer Mode (if Chrome/Edge requires it). (Detailed steps)
  3. Click the script link: AceCodeClaimer.user.js. Tampermonkey will open an install dialog; click Install.
  4. Restart your browser. Then visit stake.com.
  5. Connect & Auto-Claim: When the page loads, look for the “Connect” button injected by the script. Click it (if it doesn't auto-connect). Enjoy automated code claiming!

If any of these steps are unclear, or if you prefer a more thorough explanation, see the detailed instructions below.

Introduction

Ace Code Claimer is a small program (a “userscript”) that runs inside your browser via Tampermonkey. When you visit Stake.com, it watches for bonus codes and automatically redeems them—often faster than any human could. This lets you collect daily/weekly or promotional drops with minimal effort.

Detailed Instructions

1. Install Tampermonkey

If you already have Tampermonkey installed and know how it works, you can skip down to the Developer Mode step if needed. Otherwise, follow these instructions for your browser of choice:

Chrome

  1. Go to the Chrome Web Store link for Tampermonkey.
  2. Click Add to Chrome, then confirm by clicking Add extension.
  3. Once installed, an icon (black square with two white circles) appears in the top-right corner.

Edge

  1. Go to Tampermonkey in the Edge Add-ons.
  2. Click Get or Add, then allow the installation.
  3. After installation, confirm Tampermonkey is active (top-right puzzle icon if hidden).

Firefox

  1. Open the Tampermonkey Add-on page.
  2. Click Add to Firefox, then Add in the prompt.
  3. Once installed, the Tampermonkey icon will appear. If not, check the Add-ons menu.

2. Enable Developer Mode

Some Chromium-based browsers (Chrome, Edge, Opera) might require Developer Mode to install userscripts from external URLs:

  • In Chrome/Brave/Opera, go to chrome://extensions and toggle Developer mode on (top-right corner).
  • In Edge, go to edge://extensions, enable Developer mode (bottom-left), and allow other store extensions if prompted.
  • Firefox does not require Developer Mode for Tampermonkey or userscripts.
  • While still on the chrome://extensions (or similar) page, locate Tampermonkey, click Details, and toggle Allow User Scripts to on.

3. Install the Ace Code Claimer Script

  1. Click this link: AceCodeClaimer.user.js. Tampermonkey should open an “Install script” dialog.
  2. Review the script info (name, version, domains) and click Install.
  3. After installation, check that Ace Code Claimer” is listed in your Tampermonkey dashboard.

4. Restart Your Browser

For the best results, close all browser windows and reopen so that Tampermonkey and the new script load completely.

5. Open Stake.com

  1. Go to stake.com. Log in to your account.
  2. The script inserts a small header or panel on the page (usually at the top). You’ll see a Connect button and settings.
  3. Click Connect to link with the code-claim server. Once the status is Connected, you’re ready to auto-claim codes.

How It Works

Once connected, the script automatically redeems drop codes that come through its WebSocket. If a valid code is announced, the script instantly requests it on your behalf...

Tip: Many bonus codes have limited usage (e.g., first 1000 redeems). Even with an auto-claimer, codes can run out instantly. A stable internet connection helps.

Troubleshooting & Advanced Tips

Problem: The script doesn’t appear or won’t connect.
Fix: Ensure Tampermonkey is active. Check your firewall/VPN. Try another browser or disable “Sleep Tabs” (Chrome Memory Saver/Edge Sleeping Tabs).
Problem: Getting frequent Cloudflare Turnstile CAPTCHAs.
Fix: Solve the captcha to continue. If it persists, your IP or region might be flagged. Switching servers or normal play can reduce it.
Problem: “Subscription expired” or “Banned” message.
Fix: Possibly your account is restricted on the script’s server or Stake’s side. Contact the script provider or Stake support if you believe it’s a mistake.

Recommended Browser Settings

  • Exclude Stake.com from Chrome Memory Saver (chrome://settings/performance) or Edge Sleeping Tabs (Settings > System and Performance).
  • Consider using Cloudflare DNS (1.1.1.1) for potentially faster name lookups.
  • Try to keep only one Stake.com tab with the script running to avoid conflicts.
